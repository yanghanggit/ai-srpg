# 角色行为（Actor Actions）

## 大地图与地点，两套动词

世界有两层位置，含义不同，因此动词也不同。

大地图是一张网格：一格要么是空地，要么是一个地点，人站在格上。地点内部是一张图（营地、洞穴、空间站都只是内容侧的名字）：区域是顶点，父子区域互为邻边，人在区域上，没有坐标。

一个地点对外只占一格。无论在里面走到多深，对外它就是大地图上的那一格。

判据只有两条：

- 大地图是坐标系，不是场所。所以「在场者」只存在于地点内部，也只在那里能说话。
- 站在同一张大地图上不等于站在同一处。所以大地图上的移动与告知都只与自己、与大地图有关。

## 动词表

| 动词 | 只在哪一层成立 | 结果 |
| --- | --- | --- |
| 大地图移动 | 大地图 | 走到相邻一格，只改坐标；可以停在地点所在格 |
| 进入地点 | 大地图 | 从地点所在格进去，落到地点入口，摘掉自己的坐标 |
| 离开地点 | 地点内部 | 回到大地图上地点所在的那一格，无论在里面多深 |
| 区域内移动 | 地点内部 | 走到子区域或父区域；父区域是大地图时不算——那是离开地点 |
| 说话 | 地点内部 | 广播给同一区域的人与区域本身 |
| 等待 | 两层都可用 | 地点内部广播「没动」；大地图上什么都不发生 |

把「移动」拆成四个动词，是为了每个动作的前置条件都能一句话说清：在不在这一层、目标是否相邻、脚下是不是那个地点。合成一个动词时，「走到地点格」必然被解释成进入地点，站在地点上就表达不出来。

每个动词由一个 system 独占，`filter` 顺带做层级校验：层级不符的动作不会生效，也不会报错——它只是不属于这里。

## 位置的互斥表示

在地点内部：所在舞台是区域（地点入口也是区域），没有坐标。在大地图上：所在舞台是大地图，坐标是自己的格。没有第三种状态。

离开地点的落点不需要额外数据：就是地点所在的那一格。进入地点的落点也不需要：永远是地点入口。这条对称来自「地点对外只占一格」。

## 一次位置变化说给三处听

离开时旧处的区域看见他走，到达后新处的区域看见他来，他自己记住这条路线的两端。第三句不能省：别人听到的「他来了」是旁观视角，回答不了「我从哪儿来」。

投递对象由位置类型决定：

- 地点内部的位置 → 该区域的在场者与区域本身；
- 大地图上的位置 → 只写给大地图自己。

后半条是「大地图不是场所」的直接后果：在图上走动，同图上的人不该被当成旁观者叫醒，只有大地图记下这次移动。

调用顺序即语义：先发离开、再改组件、最后发到达。顺序反了，旧处会听见「他来了」。

## 一个动作一个事件

每个动词对应一个领域事件，描述「谁做了什么」：说话带上说的话，移动带上目的地，进入离开带上那个地点。事件是事实，投递是听众人数——一次移动说给三处听，事件仍然只有一条；范围只是它被谁听见。

事件与世界同源：投递进记忆的那句话就来自事件本身，所以记忆里说的与事件里记的不会走散。被拒绝的动作不产生事件：它没有发生。

事件只描述发生，不描述意图：谁为什么这么做，事件不管，那属于角色的记忆。

## 边界

行为只改位置与记忆，不改外观与环境——那些是描述刷新的职责。它挡在计划之后：计划挂动作，行为消费动作。
