# 角色计划（Actor Plan）

## 结论

计划是角色在一轮里「想」，不是「做」。它读的是这一刻自己所在的位置与能看见的东西，产出是一次工具调用；工具只负责往角色身上挂一个动作，真正生效由行为系统完成。

## 大地图与地点各有一个计划系统

位置分两层，可用的动词就分两套，所以计划也分两个系统：地点内部的计划与大地图上的计划。

两者的上下文不同：地点内部给的是区域、环境快照与在场角色；大地图上给的是脚下那一格与视野里的相邻格（格上是空地、地点，还是站着别人）。工具表也不同，各层只提供本层成立的动词。

两个系统共用同一个动作（「这个角色这一轮该想一次」），靠层级判定互斥——同一时刻只有一个会处理它。共享的只有「跑一轮 loop」这件事。

这样切分的理由是：如果留在一个系统里，上下文、工具表、可去之处三样都会变成按层分叉的分支，而且每加一层就多一叉。

## 为什么是一个动作

行动与思考分成两步：谁该想、想完做什么，都由外部决定。系统只负责「给谁想、给什么上下文、把结果记下来」。要推动某个角色，就给它挂一个只在当轮有效的动作组件；决定挂谁的代码在 system 之外。

开发期由 CLI 点名推动——一次可以指定一个或多个角色。谁都没被点名时，两个计划系统一次也不会跑。自主运行（每轮自动决定谁该行动）属于玩法策略，不属于这里；那条策略落地时会复用同一个动作，只是判定谁该挂它。

## 上下文只放这一刻

提示词里的信息都在本系统之前的一轮里刷新过，所以计划看到的是这一轮的样子，而不是上一轮。

地点内部放三样：区域、环境快照、在场角色（含各自外观）。大地图上放两样：脚下的格子、视野内的相邻格。大地图上没有环境与在场者——那是场所才有的东西。

计划是一个 agent loop，但本层所有工具都是终止工具：一次计划只落一个行动，说完、走完或不动就结束本轮。轮次上限只服务于纠偏——模型停下却没调工具时，循环会注入「必须通过工具提交」再试一次，两次仍不动就算这次计划失败，角色轮空。

## 行为以工具表达

每个工具对应一个动作组件：工具的作用只是把它挂到角色身上，真正生效由后续的行为 system 负责。处理器会拒绝不属于本层的动作，所以层级边界在代码里也是守住的——大地图上的计划挂不上「说话」。

一次计划只落一个行动。同一条回复里多调了工具，后到的会被忽略并在回执里说明——模型看到「本轮已经有行动了」，就不会为同一件事反复尝试。

「原地不动」是两端都保留的工具：没有它，「这一轮什么都不做」就只能靠模型不调工具来表达，而那恰好与「忘调用」无法区分。大地图上的等待不产生广播，但它仍是显式选择。

工具的语义归各自的 system 所有，所以定义与处理函数都放在系统内部——它们是这一层的系统在「这一刻」能发起的行为，不是通用工具库的一部分。

## 接管写的是同一份记忆

开发期由 CLI 直接给角色下命令（说话、大地图移动、进入地点、离开地点、区域内移动、原地不动）。命令不绕过这条链路：它挂上「该想一次」与那个行为动作，计划系统在 pipeline 的原位看到已决定的动作，就不再问模型，只把决策写成记忆。

于是记忆里同样是三条：这一轮的输入、带工具调用的回复、回执。输入还是压缩版的那一版，与自主计划写下的逐字相同；顺序也一样——先有这一轮的环境与在场者，再有自己的决定。事后翻记忆，看不出哪一轮是人下的命令。

玩家能做的与模型能做的由同一套前置条件决定（层级、相邻、脚下是不是那个地点），只是玩家在跑 pass 之前就被拦下来并拿到原因，而模型是在下一轮从工具回执里学到。绑定校验默认打开：只能命令自己控制的角色，`--force` 供开发期直接驱动没有绑定过的角色。

## 大地图上的视野

大地图上的可见范围是相邻八格加上脚下那一格：地点与别人都写在「视野」里。脚下是什么由位置行回答，所以视野不重复它；但**同一格上的人必须写出来**——把「这里是什么」和「这里有谁」一起省掉，同格的两个人就互相瞎了。

视野只给事实，不给判断：哪一格能走、能不能进入地点，交给动词的约束去拒。

## 失败就是轮空

计划失败（请求异常、循环中止）只记一条警告：这个角色本轮没有行动，下一次被点名时再想。它不抛给 pipeline，也就不触发整次 pass 的回滚——思考失败不该让世界倒退。

这条边界与描述刷新一致：预期内失败由 system 自己消化。

## 边界

计划本身只挂动作，不改位置、不发布领域事件。它读的是记忆、描述组件的当前值与位置，因此必须排在描述刷新之后，否则计划看到的会是尚未刷新的旧描述。

## 看到的与听到的

计划看到的上下文是「此刻」的快照：环境、在场角色、相邻格。它看不到同一轮里别人刚说的话——同一轮内所有计划都在任何广播之前完成（先想完所有人，再一个个生效）。要对话，就一轮点一个人，让他的话先落到别人记忆里。
